Keepsafe

Put a screen time code out of your own reach — until a date passes, until you count your way out, or both.

Eight characters or more. It encrypts everything on this device. There is no reset.

How it works

  • Everything stays in this browser. No account, no server, nothing sent anywhere.
  • The vault is encrypted with your password (PBKDF2 · 310,000 rounds → AES‑GCM 256).
  • A puzzle lock is real: the code is encrypted with the answer, so the count has to be done.
  • A date lock is a promise, not a cage — see the honesty note in the README.
