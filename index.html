How it works

  • One password, the one you type above. It encrypts everything on this device, it is never stored, and there is no reset.
  • Codes are locked away behind a date, a counting puzzle, or both.
  • A code can be typed into your phone one digit at a time, so you can set it without ever seeing it whole.
  • Nothing is sent anywhere. Keep the backup file — a browser can lose its storage.
